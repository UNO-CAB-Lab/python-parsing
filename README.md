# CBA CAB Lab 

This module is part of the UNO's CBA CAB Lab project to expand the labs usage to everyone interested in using it. It provides a set of tools that automatically map question data from Qualtrics to the data that is generated through instruments (iMotions). In this process, it generates a SQLite database that can be used directly.  However, it also contains numerous helpful functions for selecting and filtering the data you want for analysis. This project is managed by Ben Smith, so please reach out to him if you have any questions.

How do I install this module?

To install this module, you can use pip:
```
pip install CBACABLab
```

To install this module with conda, you can use the following command:

```
conda install -c tazzben CBACABLab
```

If you don't yet have Python installed, we recommend installing Anaconda, which is a open-source distribution of Python that includes useful packages for data analysis. You can download Anaconda from [here](https://www.anaconda.com/products/distribution). We also recommend you install Microsoft [Visual Studio Code](https://code.visualstudio.com/) to work with notebook files.
